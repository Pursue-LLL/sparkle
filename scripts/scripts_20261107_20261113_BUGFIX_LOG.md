## BUG-2026-11-13-005 升级反复打断：重复安装 + 每轮重新输管理员密码

| 字段 | 内容 |
| --- | --- |
| 出现 | 长期存在；11-13 19:38 / 19:40 / 19:42 三次 App 启动为同一构建（CDHash `b42edc22…`）的重复安装 |
| 现象 | ① 一次升级命令导致 App 被反复退出重启，用户工作被打断；② **每轮重启都弹系统密码框**，用户需反复输入管理员密码；③ 源码未变时重跑命令仍然 quit + 覆盖 + 重启 |
| 根因 1：密码弹窗 | `ditto` 复制**不保留 root 属主与 setuid 位**（实测：源 `-rwsr-xr-x` → ditto 后 `-rwxr-xr-x`）。App 启动时 `tunStartupGuard` 检查当前启用内核（`config.yaml` 的 `core`）的 setuid，缺了就走 `permission.ts` 的 `osascript … with administrator privileges` 弹框重新授权。每次安装都丢位 ⇒ 每次启动都要重新输密码 |
| 根因 2：多次启停 | `install-sparkle-local.sh` 无条件 quit + ditto + 启动（1 次启停）；`upgrade-sparkle-local.sh` 的 `max_recovery_rounds` 默认 2，每轮恢复都 quit + 重新 open（最多再 2 次）。一条命令最坏 = 3 次启停 = 3 次密码框 |
| 根因 3：空操作也打断 | 源码未变时 CDHash 与 `dist` 完全相同（实测 `b42edc22…` 两边一致），但安装流程不做任何比对就 quit + ditto + 启动 |
| 根因 4：无并发保护 | `scripts/` 里没有任何 `flock` / 原子锁，两个升级可同时写 `dist` 与 `/Applications`（BUG-2026-11-13-004 的直接成因） |
| 修复了什么 | ① `install-sparkle-local.sh`：quit 之前做**幂等短路**——CDHash 一致 + App 在跑 + `:7890` 通 + 启用内核 setuid 完整，四者全中直接 `exit 0`（`SPARKLE_FORCE_REINSTALL=1` 可强制）；② ditto 后调 `lib/core-setuid.sh` 的 `restore_core_setuid`，用**一次**提权给当前启用内核 `chown root:admin` + `chmod +sx` 并断言仍在，失败则中止安装；③ `sparkle-service` 改为先发普通信号，只有确实停不掉且非非交互模式才提权一次；④ 恢复轮次默认 2 → **0**（显式设 `SPARKLE_POST_INSTALL_RECOVERY_MAX_ROUNDS` 才放开，上限 3）；⑤ `agent-sparkle-upgrade.sh` 与 `upgrade-sparkle-local.sh` 各持一个原子 `mkdir` 锁（pid + 启动时间，持有者已死或超 1 小时才接管，`INT/TERM` 释放后退出）；⑥ 看门狗与 profile scheduler 安装改为幂等 |
| 遗漏了什么 | ① 我最初用 `tsx -e "<script>" "$mode"` 传权限位做 setuid 判断，而权限位以 `-` 开头，被 node 当成命令行选项（`bad option: -rwxr-xr-x`）导致脚本崩溃——且崩溃点在已经 quit 掉 App 之后，实际让用户的 App 停了一次；② 该缺陷早期没被发现，是因为我用 shell 变量插值测那条命令，绕开了传参问题，本地看着是好的，真机才爆；③ 曾错误地想在 `deepSignMac.cjs` 里给 `dist` 补 setuid，但构建以普通用户运行 `chown root:wheel` 必然失败，且签名后改权限无意义，已完全撤回 |
| 导致了什么 | 用户反复被打断、反复输密码；过程中我的一次误操作让 App 停止运行（已立即恢复，代理未中断，因 `sparkle-service` 与 root 内核不受影响） |
| 验证 | 实跑 `install-sparkle-local.sh`：输出 `Same build already installed and healthy (CDHash b42edc22…) — nothing to do, app untouched`，App pid 58869 **未变**，短路标记正确写入；`lib/core-setuid.sh` 9 个功能测试全通过（真实 source 后跑判定、`ditto` 丢位后判缺失、非交互拒绝提权且不改权限位、sidecar 缺失报错）；全量 1751/1751 通过；typecheck 与 ESLint 干净 |
